ABOUT THE PROJECT

How TruthLens AI Works

TruthLens AI is built on a classic but powerful natural language processing pipeline. News articles from a labeled dataset of real and fake news are cleaned and transformed into numerical features using a TF-IDF (Term Frequency–Inverse Document Frequency) vectorizer, which captures how important each word is relative to the entire corpus.

These features are then fed into a Passive Aggressive Classifier, an online learning algorithm well-suited for large-scale text classification tasks. The trained model and vectorizer are serialized with Joblib and loaded by the Flask backend to serve real-time predictions.

# Vectorize text using TF-IDF
vectorizer = TfidfVectorizer(
    stop_words="english",
    max_df=0.7
)
X_train_tfidf = vectorizer.fit_transform(X_train)

# Train the classifier
model = PassiveAggressiveClassifier(
    max_iter=1000
)
model.fit(X_train_tfidf, y_train)

# Save with joblib
joblib.dump(model, "fake_news_model.pkl")
